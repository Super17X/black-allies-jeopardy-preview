# Media permission register

No written licenses, ownership declarations, or distribution permissions were found in the supplied project documentation. **No supplied audio or artwork is verified for customer distribution.** Filenames and inclusion in a repository are not permission evidence.

The companion ASSET-PERMISSIONS.json identifies media with SHA-256 hashes. Embedded artwork in index.html also needs provenance. External script libraries have their own licenses and should be included in a separate dependency review.

Before releasing a media-bearing customer build, attach the creator/rightsholder, source, license text or signed grant, allowed distribution and commercial uses, required credit, restrictions, and verification date to each item. Replace assets without sufficient evidence with original or appropriately licensed work.

Verified-media-only mode mutes supplied recorded clips and hides supplied images/background artwork during play. It does not remove media files from the repository or certify permission. A distributable media-free package must also exclude the unverified files and embedded artwork.

Practice-round content and styling added in this update use no supplied audio or artwork.
