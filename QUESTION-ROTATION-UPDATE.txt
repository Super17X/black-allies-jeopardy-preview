SMART QUESTION ROTATION

What changed:
- The browser now remembers recently used clue text across games.
- With Randomize Board ON, unseen questions are selected before previously seen questions.
- Previously seen clues are recycled oldest-first only after the available category pool is exhausted.
- History persists through refreshes/restarts using localStorage.
- Host Controls now includes “Reset Question Rotation”.
- Existing question count, scoring, categories, Supabase realtime, buzzer, and 7-second steal behavior are unchanged.
- Important: a category currently containing exactly the same number of bank questions as the configured Questions/category must necessarily reuse that full category. The rotation engine automatically becomes more powerful as additional questions are added to that category.
- Mascot CSS also includes an additional head/body overlap hotfix.
