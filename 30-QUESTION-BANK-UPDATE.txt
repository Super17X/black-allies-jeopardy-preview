How rotation works:
- A normal game still displays the configured number of clues per category.
- With Randomize Board ON, the game prioritizes clues that have not appeared recently.
- Used clue history is stored locally in the host browser.
- Older clues rotate back in only after the available unseen pool is depleted.
- Host Controls includes Reset Question Rotation.
