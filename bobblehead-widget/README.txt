BLACK & ALLIES JEOPARDY — BOBBLEHEAD HOST WIDGET

The widget is browser-only and GitHub Pages compatible.
No backend and no API key are required.

Files:
css/bobblehead.css
js/bobblehead.js

The mascot is drawn in CSS, so no external character artwork is required.
The widget supports greeting, category prompts, correct/wrong reactions,
7-second steal prompts, Daily Double, Final Jeopardy, and winner messages.

JavaScript API:
BobbleHost.event("greet")
BobbleHost.event("choose")
BobbleHost.event("correct")
BobbleHost.event("wrong")
BobbleHost.event("steal")
BobbleHost.event("daily")
BobbleHost.event("final")
BobbleHost.event("winner")
BobbleHost.show("Custom message")
